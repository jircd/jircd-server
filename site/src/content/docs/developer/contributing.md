Read the repository's [contribution guide](https://github.com/jircd/jircd-server/blob/main/CONTRIBUTING.md) for its spec-driven workflow and pull request process. Report vulnerabilities through the private channels in the [security policy](https://github.com/jircd/jircd-server/blob/main/SECURITY.md), not public issues.

Feature work is tracked under [`specs/`](https://github.com/jircd/jircd-server/tree/main/specs); see the contribution guide for how specifications, plans, and tasks fit together. The project's engineering principles are in the [constitution](https://github.com/jircd/jircd-server/blob/main/.specify/memory/constitution.md).

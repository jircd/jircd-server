# Documentation

The guides and the home page of [jircd.org](https://jircd.org) are Markdown files in
[`site/src/content/docs/`](../site/src/content/docs/). Edit them there; the site workflow checks
links (the Astro build checks the links between site pages, and the workflow's API check covers
the links into `/api/`) and publishes the result. See [`site/`](../site/) for the Astro Starlight project.
